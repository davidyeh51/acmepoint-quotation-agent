## 📌 專案背景與業務現況痛點解決

在太陽光電與儲能電廠運維流程中，標準報價流程歷經六大步驟：
```
  [1. 客戶需求提出] ──(業務轉工程師)──► [2. 工程師請採購找廠商]
                                                │
  [4. 廠商提供報價單給採購] ◄──(確定規格內容)── [3. 工程師與廠商技術對談]
             │
             ▼
  [5. 業務重新整理廠商報價 ──► 疊加規定毛利 ──► 轉成內部 Excel / B2B 報價單]
             │
             ▼
  [6. 客戶回簽用印 ──► 全流程結案歸檔]
```

### 💡 本系統透過 AI Agent 實現的四大核心升級：
1. **智能拆解與資料庫化**：支援自然語言對話輸入或直接上傳廠商報價單（PDF、Excel、圖檔），AI 自動秒級解析廠商名稱、工項、工數、單位、成本單價與總計，並即時寫入雲端 PostgreSQL (Supabase) 資料庫。
2. **業務毛利覆核工作站**：提供業務一鍵選擇目標客戶（宇豐綠能、中租迪和...）、自動帶入案場地址與聯絡人；具備動態毛利率試算（15% ~ 46.7% 或自訂金額反算），支援「整批打包 1式」與「保留分項明細」雙模式。
3. **官方標準銷售報價單直接產出**：
   - 📊 **Excel (.xlsx)**：完全依照進金生官方銷售單範本（`大安龜殼-除草鋸樹作業 報價單 20261002.xlsx`）1:1 輸出，包含公式（`=D*E`、`=SUM(...)`、`=F*0.05`、`=F+F`）、六大工程條款與雙方簽署欄位。
   - 🖨️ **PDF 擬真預覽與列印**：A4 顧問級排版，支援瀏覽器一鍵列印或轉存 PDF。
4. **全端無伺服器部署與多業務協同**：純前端靜態託管（GitHub Pages）結合 Supabase BaaS，其他業務員打開瀏覽器即可直接使用，隨時查閱歷史報價紀錄並追蹤回簽狀態。

## 🚀 快速開始與使用教學

### 步驟 1：輸入對話或上傳檔案
- **點擊「載入大安龜殼除草範本」**：系統自動填入保淨清潔 5 項工項（模組下方除草 4工、藤蔓 2工、割枝 1工、吹葉 1工、管銷 1式，未稅共 NT$ 24,000）。
- **或直接貼上對話**：例如業務在 LINE 收到採購發來的工項與報價，直接貼在輸入框點擊「AI 智能拆解與萃取」。
- **或上傳檔案**：拖曳廠商 PDF 或 Excel 至拖曳區。

### 步驟 2：業務毛利覆核工作站
- **勾選對象客戶**：下拉選擇客戶（例如：`宇豐綠能股份有限公司`），系統自動帶出統一編號、裝置地址（`台中市大安區新龜壳段917地號`）、窗口聯絡人（`廖基宏`）。
- **決定毛利**：
  - 點擊快捷按鈕 `★ 46.7% (範本定價)` 或拉動滑桿。
  - 或於右側直接輸入目標銷售金額 `45000`，系統自動反算毛利潤 `NT$ 21,000`、營業稅 `NT$ 2,250`、含稅總額 `NT$ 47,250`。
- **呈報型態切換**：
  - 🔘 **整批打包 1式 (範本標準)**：對客單據呈現「除草工程 1式 45,000元」，規格備註保留細項說明。
  - 🔘 **保留分項明細報價**：保留 5 項工道明細，各別分攤銷售單價。

### 步驟 3：產出官方標準單據
- **下載 Excel 報價單**：點擊「一鍵下載標準 Excel 報價單 (.xlsx)」，即可下載與官方範本 100% 相同格式的試算表。
- **預覽 / 列印 PDF**：點擊開啟擬真 A4 報價單，直接列印或另存 PDF 發送給客戶。
- **儲存至雲端**：點擊「業務覆核核准」或「儲存為草稿」，資料同步存入 Supabase。

### 步驟 4：流程結案（登記客戶回簽）
- 進入「3. 報價單總覽與生命週期」頁籤。
- 當收到客戶蓋章簽回時，點擊「登記客戶回簽」按鈕，上傳簽回掃描檔或註明回簽日期，完成整套閉環！

## 🗄️ Supabase 資料庫建置指南

若欲在您專屬的 Supabase 專案中建立完整資料結構：
1. 登入 [Supabase Dashboard](https://supabase.com/dashboard)。
2. 進入專案的 **SQL Editor**。
3. 複製專案目錄下的 `supabase-schema.sql` 內容並貼上執行 (Run)。
4. 該腳本將自動建立：
   - `quote_customers` (客戶主檔)
   - `quote_vendors` (協力廠商主檔)
   - `vendor_quotes` / `vendor_quote_items` (廠商成本主明細)
   - `sales_quotes` / `sales_quote_items` (業務銷售主明細)
   - 完整的 RLS 安全規則與大安龜殼除草標準範本種子資料！
5. 在平台網頁右上角點擊「設定」，填入專案之 `Project URL` 與 `Anon Public Key` 即可！

## 🌐 GitHub Pages 部署步驟

本專案為零建置成本之純前端架構：
1. 將專案推播至 GitHub 倉庫（如 `davidyeh51/acmepoint-quotation-agent`）。
2. 進入倉庫 **Settings** -> **Pages**。
3. **Build and deployment** 來源選擇 `Deploy from a branch`。
4. 分支選擇 `main`，資料夾選擇 `/ (root)`，點擊 **Save**。
5. 數秒後即可獲得專屬線上網址，所有業務同仁皆可直接開啟使用！
